本模块以 Jupyter Notebook 为主讲解载体（gru.ipynb、lstm.ipynb、deep-rnn.ipynb、bi-rnn.ipynb、encoder-decoder.ipynb、seq2seq.ipynb、beam-search.ipynb、machine-translation-and-dataset.ipynb），并配套两个可独立运行的 Python 脚本：
- lstm.py：分四段组织——从零实现 LSTM（参数初始化/state/前向）、简洁实现（nn.LSTM）、北京 PM2.5 时间序列预测（自定义 nn.Module + DataLoader）、字符级语言模型（Embedding+LSTM+FC），通过 `if __name__ == "__main__"` 切换运行。
- seq2seq.py：按“模型定义→损失与遮蔽→训练/预测→BLEU 评估→主程序”五段结构，封装 Seq2SeqEncoder(Seq2SeqDecoder) 继承 d2l.Encoder/Decoder，使用 GRU 作为核心循环单元；训练流程包含 Xavier 初始化、Teacher Forcing、梯度裁剪、MaskedSoftmaxCELoss 与 BLEU 指标。
- seq2seq.mmd 提供 Mermaid 流程图描述数据流与张量形状变化，辅助理解编码器-解码器内部维度变换。
依赖方向：所有代码均依赖 d2l.torch 提供的数据集加载、训练循环、可视化工具，以及 torch.nn、torch.optim、matplotlib、pandas、sklearn 等通用库，模块内文件之间无相互 import，仅通过 d2l 接口与外部生态交互。
