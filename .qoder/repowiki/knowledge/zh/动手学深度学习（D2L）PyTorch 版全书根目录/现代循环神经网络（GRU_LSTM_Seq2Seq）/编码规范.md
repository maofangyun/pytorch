- 每个 Notebook 对应一个具体主题（GRU/LSTM/Deep-RNN/Bi-RNN/Encoder-Decoder/Seq2Seq/Beam Search），并通过 index.ipynb 的 toc 标签统一索引导航。
- Python 脚本采用分段注释（`# ==== 第X部分：... ====`）划分功能模块，并在 `if __name__ == "__main__"` 中提供可切换的运行入口。
- 模型类继承 d2l.Encoder/Decoder 基类，统一实现 `forward` 与 `init_state` 接口，保持编码器-解码器结构一致。
- 序列长度不一致时统一使用 `sequence_mask` + `valid_len` 进行填充屏蔽，配合自定义 `MaskedSoftmaxCELoss` 计算有效 token 的平均损失。
- 训练循环遵循固定模式：`optimizer.zero_grad()` → 前向 → 损失求和 `.sum().backward()` → `d2l.grad_clipping` → `optimizer.step()`，并使用 `d2l.Accumulator` 统计 loss 与 token 数。
- 设备管理统一通过 `d2l.try_gpu()` 获取 GPU/CPU 设备，并将所有张量 `.to(device)` 迁移后再参与计算。
