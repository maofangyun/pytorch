本模块由一组相互独立的 Jupyter Notebook 组成，按教学顺序组织：`index.ipynb` 作为目录索引，依次串联 image-augmentation → fine-tuning → bounding-box → anchor → multiscale-object-detection → object-detection-dataset → ssd → rcnn → semantic-segmentation-and-dataset → transposed-conv → fcn → neural-style → kaggle-cifar10 → kaggle-dog。每个 notebook 自包含完整的导入、数据加载、模型定义、训练与可视化代码，彼此之间通过概念引用（如 `:numref:`sec_transposed_conv``）而非代码依赖耦合；`submission.csv` 是 Kaggle 提交结果文件。整体采用“单笔记本一主题”的扁平结构，无 Python 包或构建脚本。
