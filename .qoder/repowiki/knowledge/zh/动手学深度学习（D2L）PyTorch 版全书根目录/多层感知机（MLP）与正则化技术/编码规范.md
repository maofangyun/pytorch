- 每个主题同时提供两个版本：从零开始的 Python 脚本（如 `mlp-scratch.py`、`weight-decay.py`）与对应 Jupyter Notebook（如 `mlp-scratch.ipynb`、`weight-decay.ipynb`），便于对照学习。
- 所有脚本统一通过 `from d2l import torch as d2l` 引入 d2lbook 工具，使用 `d2l.load_data_fashion_mnist`、`d2l.train_ch3`、`d2l.Animator` 等封装函数完成数据加载、训练循环与可视化。
- 模型定义遵循两种风格：从零实现时使用 `nn.Parameter` 手动声明权重与偏置，简洁实现时继承 `nn.Module` 或使用 `nn.Sequential` 组合层。
- 训练代码包裹在 `if __name__ == '__main__':` 块中，并通过断言（`assert`）验证训练结果的合理性（如准确率范围、损失上界）。
- Dropout 仅在训练模式下启用：通过检查 `self.training` 标志或在 `net.train()` 后调用，测试时直接返回原始输入。
