- 每个notebook开头统一导入`import torch`、`from torch import nn`、`from d2l import torch as d2l`，并通过`@tab["pytorch"]`元数据声明框架变体。
- 数据集相关函数和常量使用`#@save`注释标记，以便被d2l工具链导出复用。
- 模型类继承`nn.Module`，在`__init__`中定义embedding/encoder/decoder组件，在`forward`中按“编码→池化/对齐→全连接输出”的顺序组织计算图。
- 权重初始化通过自定义`init_weights`函数配合`net.apply(init_weights)`统一处理Linear和LSTM参数。
- 多序列输入形状约定为`(批量大小, 时间步数)`或`(批量大小, 序列长度, embed_size)`，并在forward中对时间维做转置以满足RNN输入要求。
