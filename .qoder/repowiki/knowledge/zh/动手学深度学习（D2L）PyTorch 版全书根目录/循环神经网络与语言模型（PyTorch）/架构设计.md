本模块由一组相互独立的 Jupyter Notebook 组成，按学习路径组织：`index.ipynb` 作为章节入口，依次链接 `sequence`→`text-preprocessing`→`language-models-and-dataset`→`rnn`→`rnn-scratch`→`rnn-concise`→`bptt`。每个 notebook 自包含一个主题，代码通过 `from d2l import torch as d2l` 复用统一的数据加载、可视化和工具函数；数学公式以 Markdown + LaTeX 形式嵌入，训练/演示代码以可执行 cell 呈现。依赖方向单向指向 d2l 工具包，各 notebook 之间不互相 import，仅通过 index 的目录结构串联内容。
