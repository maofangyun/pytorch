本模块以 Jupyter Notebook 为主教学载体，辅以独立的 Python 脚本示例：`index.ipynb` 作为章节入口汇总各小节；`model-construction.py` 演示 `nn.Sequential`、自定义 `nn.Module`（如 `MLP`、`MySequential`、`FixedHiddenMLP`、`NestMLP`）及嵌套组合；`parameters.py` 覆盖参数访问、`state_dict`、`apply` 批量初始化、共享参数绑定等。其余 `.ipynb` 文件分别聚焦延迟初始化、自定义层、读写模型、GPU 使用。`mlp.params` 为训练保存的权重文件，`mydict` 与 `x-files` 为配套数据目录。依赖方向单一：所有代码仅依赖 `torch` 与 `torch.nn`，不引入其他框架，形成“概念→脚本→Notebook”的递进结构。
