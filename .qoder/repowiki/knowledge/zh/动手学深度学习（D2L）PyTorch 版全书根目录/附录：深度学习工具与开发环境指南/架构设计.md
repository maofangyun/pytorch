本模块是一个纯文档型附录，由 index.ipynb 作为入口聚合所有子章节，每个 .ipynb 文件独立讲解一个工具主题（jupyter、aws、sagemaker、selecting-servers-gpus、contributing、d2l），彼此之间无代码依赖，仅通过 :ref: 和 :numref: 交叉引用关联。内容以 Markdown 单元格为主，穿插 bash/Python 代码块演示实际操作，图片资源统一通过 ../img/ 相对路径引用。d2l.ipynb 使用 eval_rst + autoclass/autofunction 从 d2l.torch 源码自动生成 API 文档，是本章唯一与 Python 包产生静态依赖的地方。
