本仓库是《动手学深度学习》PyTorch 版的教程集合，以 Jupyter Notebook 和少量 .py 脚本为主，**没有统一的错误处理框架或自定义异常体系**。错误处理呈现为分散、教学导向的轻量级模式：

1. **可选依赖的 try/except ImportError**：在 `chapter_linear-networks/linear-regression-scratch.py` 中，通过 try/except 捕获 d2l 包未安装时的 ImportError，打印提示并降级到无可视化模式。这是一种常见的“优雅降级”策略。

2. **网络/IO 异常的简单捕获**：在 `chapter_recurrent-modern/lstm.py` 中，对 pd.read_csv 下载数据集的操作使用 try/except Exception 捕获网络错误，打印友好提示信息后直接 return 退出函数。

3. **环境兼容性补丁而非异常处理**：在 `chapter_recurrent-modern/seq2seq.py` 中，通过 monkey-patch 替换 d2l.Animator 为 AnimatorFixed 类来规避非交互式环境的 NotImplementedError；同时修复 Windows 下 GBK 编码导致的 UnicodeDecodeError。这些属于环境适配而非真正的错误处理逻辑。

4. **无自定义异常类型**：整个代码库未发现任何 class ... Error 定义，也没有 raise 自定义异常的模式。所有错误都依赖 Python 内置异常（ImportError、Exception、UnicodeDecodeError、NotImplementedError）。

5. **无 panic/recover 机制**：作为 Python 项目，不存在 Go 风格的 panic/recover，也未见类似 try/finally 的资源清理模式。

6. **无中间件或全局错误处理器**：由于主要是独立脚本和 Notebook，没有 Web 服务或 API 层，因此不存在中间件式的错误拦截。

**开发者应遵循的规则**：
- 对于可选依赖，使用 try/except ImportError 并提供降级路径
- 对于外部 IO（网络、文件），使用 try/except 捕获具体异常并给出用户友好的中文提示
- 避免吞掉异常（bare except），至少记录异常信息
- 教学代码以简洁为先，不强制要求生产级的错误处理规范
